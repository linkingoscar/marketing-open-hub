# Getting Support & Community Channels

We want to make sure you get help quickly and through the appropriate channel.

---

## 1. Where to Ask

| Type of Request               | Recommended Channel                                                                                                  | Details                                                         |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| **Software Bug**              | [GitHub Issues](https://github.com/linkingoscar/marketing-open-hub/issues/new?template=bug_report.yml)               | Use the Bug Report template with reproduction steps.            |
| **Statistical Discrepancy**   | [Statistical Bug Report](https://github.com/linkingoscar/marketing-open-hub/issues/new?template=statistical_bug.yml) | Compare with R / SciPy / SPSS output with reproducible data.    |
| **Feature / Method Proposal** | [Feature Request](https://github.com/linkingoscar/marketing-open-hub/issues/new?template=feature_request.yml)        | Propose marketing science methods or UI tools.                  |
| **Security Vulnerabilities**  | [Security Policy](./SECURITY.md)                                                                                     | Follow private reporting procedures; do not open public issues. |
| **Academic Discussions**      | [GitHub Discussions](https://github.com/linkingoscar/marketing-open-hub/discussions)                                 | Methodological debates, paper citations, best practices.        |

---

## 2. Statistical Feedback Policy

For any question regarding statistical formula accuracy, reference datasets, or reporting conventions (APA 7th edition), we require comparison with an established reference implementation (e.g. R `stats`, Python `scipy.stats`, or JASP). See [`docs/statistics-validation.md`](./docs/statistics-validation.md) for details.
