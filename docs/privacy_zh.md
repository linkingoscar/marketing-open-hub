# 隐私政策与数据处理规范

[English](./privacy.md) | [中文](./privacy_zh.md)

生效日期：2026年9月

`marketing-open-hub` 坚定致力于保护广大学术研究人员与商业分析师的数据隐私与科研保密性。本文档详细说明了工作台在各个环节的数据处理与存储方式。

---

## 1. 本地优先处理（默认机制）

1. **科研数据集 (Research Datasets)**：
   - 导入到工作台的任何 CSV、TSV 或 JSON 文件完全在用户设备本地内存中解析与计算。
   - 原始表格数据**绝不**上传至我们的服务器，亦不会在任何远程位置建立缓存。
2. **API 凭据 (API Keys)**：
   - 用户填写的 LLM API Key 在浏览器端通过 Web Crypto API (AES-GCM 256-bit + 96-bit 随机 IV) 进行静态加密存储。
   - 密钥保存在 IndexedDB/LocalStorage，严禁以明文形式持久化。
3. **工作台状态与收藏 (Workspace State)**：
   - 工作流进度、项目收藏和分析历史保存在浏览器本地持久化存储中，可随时在设置中一键清空。

---

## 2. 外部网络通信边界

仅在用户主动触发相关功能时，工作台会发起以下网络请求：

1. **同源 AI 对话代理 (`/api/chat`)**：
   - 仅在用户使用 AI 研究助手或论文润色功能时，提示词与上下文将转发至用户配置的官方模型提供商。
   - 除非用户主动将表格摘要复制至对话输入框，否则原始数据表格绝不被发送给大模型提供商。
2. **公开学术检索 API (Semantic Scholar 等)**：
   - 在文献检索模块中，检索关键词将被发送至公开学术开放 API（如 Semantic Scholar, CrossRef, arXiv）以获取文献题录与摘要元数据。
3. **可选遥测与分析 (Telemetry & Analytics)**：
   - 仅在部署环境显式配置了 `NEXT_PUBLIC_POSTHOG_KEY` 时启用 PostHog 匿名分析。
   - 严格尊重浏览器的 `Do Not Track (DNT)` 免追踪请求。
   - 遥测仅采集匿名的交互事件与页面访问量，绝不采集用户上传的任何科研数据、Prompt 内容或私有密钥。

---

## 3. 如何彻底清除本地数据

你可以随时完全移除本地存储的所有数据与凭据：

1. 访问工作台的 **设置** (`/settings`) 页面。
2. 点击 **清空本地数据与凭据**。
3. 或直接在浏览器安全与隐私设置中清除该站点的本地存储与 Cookie。
