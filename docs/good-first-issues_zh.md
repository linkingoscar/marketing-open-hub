# 新手友好任务指南 (Good First Issues)

[English](./good-first-issues.md) | [中文](./good-first-issues_zh.md)

欢迎参与贡献！如果你想为 `marketing-open-hub` 提交第一个 PR，以下是精心整理的高价值、低门槛任务清单。每个任务均具备清晰的目标范围、较低的架构耦合度以及明确的验证步骤。

---

## 1. 扩充 `tests/reference/` 中的基准参考数据集

- **方向**：统计测试与算法质量
- **任务说明**：从公开学术文献或标准 R 数据包（如 `datasets::mtcars`, `datasets::iris`）中提取经过同行评议的标准输出案例，补充到 `tests/reference/stats-reference.test.ts` 中。
- **所需技能**：基础 TypeScript，熟悉 R 或 Python SciPy。
- **验证方式**：运行 `pnpm test` 确认在浮点容差范围内完全匹配。

---

## 2. 工作台可访问性与 ARIA 标签补齐

- **方向**：前端交互与无障碍访问 (A11y)
- **任务说明**：审查 `src/components/workspace/` 中的按钮、下拉菜单和模态弹窗，为缺少文本描述的交互图标补充语义清晰的 `aria-label` 属性。
- **所需技能**：React, Tailwind CSS, Web 无障碍最佳实践。
- **验证方式**：使用键盘 Tab 键进行全局导航，确保焦点环与读屏标签正常展示。

---

## 3. 双语技术文档校对与润色

- **方向**：文档体系与国际化
- **任务说明**：审校 `README.md` 与 `README_EN.md` 以及 `docs/` 下的双语技术文档，统一专业术语译名，修正错别字与排版瑕疵。
- **所需技能**：Markdown 规范，中英双语学术阅读能力。
- **验证方式**：确保文档内所有相对链接均能正常跳转，排版符合 GitHub 渲染规范。

---

## 4. 丰富各营销场景的示例数据集

- **方向**：营销科学研究与数据生态
- **任务说明**：为常见营销场景（如广告 A/B 测试点击转化率、顾客满意度 5 点/7 点 Likert 问卷调研、市场细分特征数据等）提供具有真实统计特性的模拟 CSV 文件，补充至 `public/datasets/`。
- **所需技能**：基础市场营销研究知识，CSV 数据规范。
- **验证方式**：在统计分析工作台中上传该 CSV 数据集，验证各项检验均能正常运行并生成报告。

---

## 5. APA 格式报告边界排版对齐

- **方向**：学术报告导出规范
- **任务说明**：核对 `src/lib/statistics/formatters/apa.ts` 是否严谨遵循 APA 第 7 版格式规范（例如 $p$ 值小于 0.001 时写为 $p < .001$ 且省略前导零、统计量保留两位有效小数等）。
- **所需技能**：TypeScript，了解 APA 格式手册。
- **验证方式**：运行 `pnpm test` 确保 APA 文本报告生成单测全部通过。
