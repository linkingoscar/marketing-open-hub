# 系统架构与技术设计文档

[English](./architecture.md) | [中文](./architecture_zh.md)

`marketing-open-hub` 是基于 Next.js 16 (Turbopack)、React 19 与 TypeScript 构建的**本地优先市场营销与实证研究开源工作台 (Local-First Marketing Research Workbench)**。

## 核心设计原则

1. **解耦的纯统计计算层**：
   所有统计检验与数学推断均在 `src/lib/statistics/` 中实现为纯 TypeScript 函数。函数接收标准数值数组或矩阵，返回强类型的 `StatisticalResult` 对象。计算引擎**零依赖** React、DOM 或浏览器上下文，可在 Node.js、Web Worker 或 Vitest 自动化测试环境中无头无缝运行。

2. **本地优先与隐私保护 (Local-First Privacy)**：
   用户通过 CSV 或 Excel 导入的实证数据集，完全在用户浏览器本地内存与 Web Worker 中进行解析和统计运算，**绝不上传**到任何外部服务器或第三方后端。

3. **统计成熟度分级治理 (`ValidationLevel`)**：
   每种统计检验方法均有明确的成熟度标识：
   - `validated`：在 `tests/reference/` 中经由 R / SciPy 成熟计算实现多组基准用例（含临界显著性边界用例）对拍校验。
   - `beta`：遵循经典统计教材标准算法实现并具备单元测试，正在开展多场景基准对拍。
   - `experimental`：探索性指标与近似算法（如偏度-峰度正态性检验、迭代式 CFA 近似），在 UI 中展示明确的免责与适用提示。

## 核心模块目录结构

- `src/lib/statistics/`：
  - `types.ts`：核心数据结构定义（`ValidationLevel`, `TestType`, `StatisticalResult`, `AnalysisWarning`, `APAReport`）。
  - `registry.ts`：方法注册表，包含方法说明、成熟度等级标签及学术文献引用。
  - `math.ts`：数学底层基础库（Gamma 函数、对数 Gamma、正则化不完全 Beta、卡方正则化不完全 Gamma、Student $t$ 分位数逆 CDF、矩阵运算等）。
  - `formatters/apa.ts`：APA 第 7 版标准报告与三线表格式化输出模块。
  - `tests/`：各领域检验算法实现（描述统计、参数检验、非参数检验、相关分析、回归分析、信度分析等）。
- `src/lib/crypto.ts`：Web Crypto API 封装，提供浏览器端 API Key 的 AES-GCM 256-bit 加密存储与 96-bit 随机 IV 生成。
- `src/app/api/chat/route.ts`：AI 助手同源服务端安全代理，内嵌防 SSRF 保护、私网 IP 拦截与超时熔断控制。
- `tests/reference/`：统计参考基准测试套件，使用 R 与 SciPy 计算结果作为黄金基准。
