## Reporting a Vulnerability

If you discover a security issue or vulnerability (such as an SSRF bypass, cryptographic flaw, or data leakage vector), please **do not open a public GitHub issue**.

Instead, report it via:

1. **GitHub Security Advisory**: Create a private vulnerability report via repository **Security** > **Advisories** > **Report a vulnerability**.
2. **Email**: Contact the maintainers directly at `security@marketing-open-hub.org` (or repository owner's GitHub profile email).

We will acknowledge receipt within 48 hours and work with you on an expedited fix and advisory release.
