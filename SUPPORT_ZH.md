# 技术支持与社区交流渠道

[English](./SUPPORT.md) | [中文](./SUPPORT_ZH.md)

我们希望你能以最高效的方式在适宜的渠道中获得帮助与反馈。

---

## 1. 渠道推荐指南

| 问题类型                | 推荐反馈渠道                                                                                               | 说明                                                         |
| ----------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| **系统 Bug / 运行报错** | [提交 Bug Issue](https://github.com/linkingoscar/marketing-open-hub/issues/new?template=bug_report.yml)    | 请使用 Bug 报告模板，提供复现步骤与控制台错误堆栈。          |
| **统计计算差异**        | [提交统计疑问](https://github.com/linkingoscar/marketing-open-hub/issues/new?template=statistical_bug.yml) | 请附带可复现的数据集，并提供与 R / SciPy / SPSS 的对比结果。 |
| **新功能 / 新算法建议** | [功能建议提案](https://github.com/linkingoscar/marketing-open-hub/issues/new?template=feature_request.yml) | 建议新增营销科学方法、实证研究工具或交互功能。               |
| **安全与漏洞报告**      | [安全政策](./SECURITY.md)                                                                                  | 请遵循私下负责任披露流程，切勿在公开 Issue 中披露漏洞。      |
| **学术讨论与经验交流**  | [GitHub Discussions](https://github.com/linkingoscar/marketing-open-hub/discussions)                       | 方法学探讨、论文引用分享、实证研究最佳实践交流。             |

---

## 2. 统计计算反馈规范

对于任何涉及统计计算公式准确度、参考数据集基准或报告格式规范（APA 第 7 版）的疑问，我们要求提供公认参考实现（例如 R `stats`、Python `scipy.stats` 或 JASP）的对拍输出。详细内容请参阅 [`docs/statistics-validation_zh.md`](./docs/statistics-validation_zh.md)。
